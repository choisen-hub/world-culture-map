# data/

Public-dataset layer for world-culture-map. `countries.json` is generated by
`build_public.py` and loaded by `index.html` with `fetch()` alongside the
hand-curated `data-*.js` tables (which are kept unchanged).

## Sources and licences

| Source | What is taken | Licence | URL |
|---|---|---|---|
| Wikidata (SPARQL endpoint) | sovereign states (`P31` = Q3624078) with ISO 3166-1 alpha-2 (`P297`), plus any other item carrying an alpha-2 code that the Factbook covers: labels (en/ko/ja), ISO alpha-3 (`P298`), capital (`P36`), continent (`P30`), latest population (`P1082` by point in time `P585`), currency (`P38`), basic form of government (`P122`), head of state (`P35`), head of government (`P6`), official languages (`P37`) with native labels (`P1705`) | CC0 1.0 | https://query.wikidata.org/sparql |
| CIA World Factbook, `factbook/factbook.json` mirror | religions, ethnic groups, languages, government type, legal system, capital name, conventional country names | Public domain (US government work) | https://github.com/factbook/factbook.json |
| Natural Earth, 110m Admin 0 countries (GeoJSON) | ISO code cross-check, NAME, CONTINENT, SUBREGION; the raw file is also kept for a self-hosted map | Public domain | https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson |
| Hand-curated app tables (`data-*.js`, inline `DATA`/`PROFILE`) | copied into `curated` per country so one file carries everything; the originals stay authoritative for the themed map | MIT (this repository) | https://github.com/choisen-hub/world-culture-map |

Every field in `countries.json` has an entry in that country's `sources`
object: `{source, url, retrieved}`. The UI shows the distinct sources as a
"Sources" line in the side panel and in the full country page, and the
per-field source as a tooltip on each card.

## Rebuild

```bash
cd world-culture-map
python3 -m pip install requests          # the only non-stdlib dependency
python3 data/build_public.py             # fetch (cached raw files reused) and merge
python3 data/build_public.py --refresh   # refetch everything
python3 data/build_public.py --merge-only  # rebuild countries.json from data/raw/ only
```

The full run takes about 3 to 4 minutes: the Factbook mirror is fetched one
file at a time with a 0.2 s pause (about 255 files, 404s are skipped), Wikidata
is queried per property in batches of 60 items with a User-Agent header, and
Natural Earth is a single 0.8 MB download. Node is used, when present, to
evaluate the curated `data-*.js` files; without Node the `curated` blocks are
simply omitted and the app still works.

Raw downloads go to `data/raw/` (about 10 MB, ignored by git). Only
`countries.json` (about 2 MB) is committed.

## countries.json layout

```
{
  "_meta": { generated, generator, count, sources[], stats },
  "countries": {
    "KR": {
      iso2, iso3, qid, sovereign, flag,
      name: {en, ko, ja, long_en},
      capital: {en, ko, ja},
      continent: [{en, ko, ja}],
      population: {value, as_of},
      currency: [{en, ko, ja}],
      government_form: [{en, ko, ja}],          Wikidata P122
      government_type: "presidential republic",  Factbook
      legal_system: "...",                       Factbook
      head_of_state: [{qid, en, ko, ja}],
      head_of_government: [{qid, en, ko, ja}],
      official_languages: [{qid, en, ko, ja, native}],
      religions_text: "Protestant 17%, ...",     Factbook
      religions: [{name, pct}],                  parsed from religions_text
      ethnic_groups_text, languages_text,        Factbook
      natural_earth: {name, continent, subregion, iso_n3},
      app: { e, f, c, p, g, l, official, native, gov, gov_factbook, leader, r },
            the same values in the field names index.html already uses
            (PROFILE e/f/c/p/g/l, POLITICS gov/leader, LANGUAGES official, DATA r)
      curated: { religion, profile, food, politics, movies, languages, business, regions },
      sources: { <field>: [{source, url, retrieved}] }
    }
  }
}
```

Countries are keyed by ISO alpha-2. The app indexes them by `iso3` because the
map and the curated tables use alpha-3; Kosovo is stored as `XKX` to match the
app (Wikidata uses `XKS`, Natural Earth `KOS`).

## Notes and caveats

- Wikidata statements with an end time (`P582`) or deprecated rank are dropped;
  if preferred-rank statements exist only those are kept. Heads of state and
  government are therefore whatever Wikidata currently asserts, which can lag
  or be wrong; the retrieval date is stored next to every field.
- Factbook GEC codes are mapped to ISO alpha-2 through the "Internet country
  code" field (`.kr`), with a short override table in the script (uk to GB,
  Kosovo, Antarctica, entities without an ISO code are skipped).
- `religions` is a light regex parse of the Factbook sentence and keeps the
  Factbook's own category names (not the app's Korean religion keys), so it is
  not used to colour the map; the curated `DATA` table still drives that.
